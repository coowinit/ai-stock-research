# 重点股票 AI 研究模板

> 用途：**第一次系统研究一只新股票时使用。** 目标不是预测短期涨跌，而是判断它是否值得进入长期重点研究池，并形成可直接保存为 `stocks/股票代码-股票名称.md` 的基础档案。

---

## 使用方法

1. 复制下面“AI 提问模板”的全部内容。
2. 将第一行的股票名称和代码替换成研究对象，例如：`工业富联（601138）`。
3. 发送给支持联网研究的 AI。
4. 核验关键财务数据、公司公告和主要来源。
5. 将最终结果保存为：`stocks/股票代码-股票名称.md`。
6. 如果决定加入重点股票导航，再在 `data/index.json` 的 `stocks.items` 中新增一条记录。
7. 如果还要纳入每日跟踪池，再同步修改 `daily/每日复盘模板.md` 中的“当前重点研究池”。

已有长期档案的股票，后续财报、公告和产业变化应优先使用该股票档案中的**增量更新模板**，不要反复重新做首次研究。

# AI 提问模板

请研究：**【股票名称（股票代码）】**

请对这家公司进行一次“重点股票首次研究”。

本次研究不是为了预测明天涨跌，也不要直接给出买入、卖出或目标价。真正需要回答的是：

> **这家公司为什么值得研究？核心投资逻辑是什么？哪些已经兑现？哪些仍是预期？最大风险在哪里？是否值得进入长期重点研究池？**

请使用截至回答时能够核验的最新公开资料。主要财务数据必须注明对应报告期；如果无法联网或无法核验最新资料，必须明确说明，不得把旧数据包装成最新数据。

## 一、研究规则

所有内容严格区分：

- **【事实】** 已经发生并且可以由公告、财报、交易所、公司官网等可靠来源核验的信息。
- **【预期】** 市场、机构、产业链或公司对未来的判断与规划，尚未完全兑现。
- **【判断】** 基于事实与预期形成的研究结论。
- **【未核验】** 暂时找不到可靠公开证据的信息。

资料优先级：

1. 公司年报、半年报、季报；
2. 公司正式公告；
3. 上交所、深交所、北交所、巨潮资讯；
4. 投资者关系活动记录；
5. 公司官网；
6. 权威行业资料；
7. 高可信财经媒体。

若不同来源冲突，以公司正式披露和交易所信息优先。

禁止：

- 把规划产能写成实际产能；
- 把送样写成批量出货；
- 把客户验证写成已经形成收入；
- 把市场预测写成公司已经实现；
- 因热门行业或近期股价上涨自动给出积极结论；
- 只看营收和归母净利润，不看扣非利润、现金流和盈利质量；
- 用大量技术指标代替公司基本面研究；
- 给出“必涨”“强烈买入”“确定上涨”等绝对结论；
- 预测具体涨幅或给出目标价。

## 二、输出要求

- 只返回最终 Markdown 正文，不解释分析过程。
- 不要把本提问模板重新附在答案末尾。
- 正文尽量控制在 **3000～4500 个中文字**，数据表和来源 URL 不计入。
- 核心投资逻辑控制在 **3～5 条**。
- 主要成长驱动控制在 **3～5 个**。
- 主要风险控制在 **3～5 条**。
- 逻辑证伪条件控制在 **3～5 条**。
- 最终关键观察点固定为 **3 个**。
- 没有可靠数据时写“未披露”或“未核验”，不要补造数字。
- 发现异常或矛盾时重点展开；正常项目简要说明即可。

请严格按照以下结构输出，不要增加重复的“建档摘要”“再次总结”等章节。

> 研究基准：使用截至回答时能够核验的最新公开资料，并注明主要财务数据对应报告期。

## 一、30秒看懂

用 **100～150 字**回答：

- 公司主要做什么；
- 靠什么赚钱；
- 当前最重要的业务；
- 当前最重要的增长来源；
- 当前最大问题或风险。

最后给出：

**一句话定位：**

不要使用“行业龙头、前景广阔、技术领先”等没有事实支撑的宣传式表达。

## 二、公司与商业模式

说明：

- 主要业务和核心产品；
- 主要客户是谁；
- 收入和利润主要来自哪里；
- 哪些业务贡献规模，哪些业务贡献利润；
- 商业模式是否具有持续性。

如公司业务较多，用表格简化：

| 主要业务 | 收入/占比 | 增长情况 | 盈利特征 | 判断 |
|---|---:|---:|---|---|
| 业务A |  |  |  |  |

只列真正影响投资判断的业务。

## 三、核心投资逻辑

从全部信息中只保留 **3～5 条**最重要逻辑。

每条统一写成：

### 逻辑 1：标题

**【事实】** 已经可以核验的依据。

**【预期】** 市场正在期待什么。

**【判断】** 为什么这件事可能影响未来收入、利润、现金流或估值。

**后续验证：** 未来应该观察什么数据或事件。

不要把同一逻辑拆成多个相似条目。

## 四、行业与竞争优势

重点回答：

- 行业当前处于增长、成熟、下行还是周期修复阶段；
- 主要竞争对手是谁；
- 公司真正的竞争优势是什么；
- 优势来自技术、成本、客户、规模、渠道、制造、资源还是其他因素；
- 这些优势是否已经反映到市场份额、毛利率、订单、现金流等经营结果中。

没有证据支持的“护城河”不要强行填写。

## 五、成长驱动与兑现程度

只保留未来最重要的 **3～5 个**增长驱动，并判断成熟度。

可使用：

`研发 → 样品 → 客户验证 → 小批量 → 批量 → 快速放量 → 规模盈利`

建议使用表格：

| 成长驱动 | 当前阶段 | 已兑现证据 | 尚未兑现部分 | 对未来利润影响 |
|---|---|---|---|---|
| 驱动A |  |  |  |  |

必须明确区分“已经形成收入”和“仍处验证或规划阶段”。

## 六、经营与财务质量

优先整理最近完整年度和最新报告期的核心指标：

| 指标 | 最新数据 | 同比/变化 | 判断 |
|---|---:|---:|---|
| 营业收入 |  |  |  |
| 归母净利润 |  |  |  |
| 扣非净利润 |  |  |  |
| 毛利率 |  |  |  |
| ROE |  |  |  |
| 经营现金流 |  |  |  |

然后重点判断：

- 收入和利润趋势是否一致；
- 扣非利润是否支持表面盈利增长；
- 毛利率和净利率是否改善；
- 经营现金流与净利润是否匹配；
- 应收账款、存货、资本开支是否出现异常；
- 高增长是否以明显增加负债或资金压力为代价。

正常项目简要说明，**只有异常项才重点展开**。

如存在可能影响长期逻辑的重大股东、治理或资本行为，再补充：控股股东变化、大规模减持、质押、回购、融资、股权激励、重大并购等；没有重要变化时不要机械展开。

## 七、市场预期与预期差

回答三个问题：

### 1. 市场目前主要在交易什么？

最多列 **3～5 条**。

### 2. 这些预期兑现到什么程度？

分别标记：

- 已兑现
- 部分兑现
- 尚未兑现
- 可能过度乐观

### 3. 真正值得继续跟踪的预期差是什么？

最多列 **3 条**，说明未来什么事实出现后才算验证。

## 八、估值与市场定价

选择适合该公司的估值指标，例如：

- PE
- PB
- PS
- EV/EBITDA

不需要强行全部使用。

回答：

- 当前估值大致处于历史偏低、中等、偏高还是极高位置；
- 与主要可比公司相比处于什么水平；
- 当前价格已经反映了哪些增长预期；
- 最大的估值风险来自什么。

**不要给目标价，不计算“上涨空间”。**

## 九、主要风险与逻辑证伪

### 主要风险

只保留 **3～5 条**真正可能影响长期投资逻辑的风险。

每条说明：

**风险是什么 → 如何影响收入/利润/现金流 → 应观察什么信号。**

### 逻辑证伪

提前定义 **3～5 个**需要重新评估甚至退出重点研究池的条件，例如：

- 核心业务持续失速；
- 新增长业务长期无法从验证进入量产；
- 盈利增长明显依赖非经常性项目；
- 现金流、应收或存货持续恶化；
- 核心竞争优势被竞争对手明显削弱；
- 原本最重要的行业假设发生根本变化。

证伪条件必须尽量可观察、可验证，不要写成泛泛风险提示。

## 十、未来三个关键观察点

只保留未来最重要的 **3 个**观察点。

格式：

2. **观察什么：**

3. **观察什么：**  
   **为什么重要：**  
   **什么结果代表强化 / 弱化：**

## 十二、资料来源

只列真正用于关键结论的主要来源，优先：

- 公司财报 / 公告；
- 交易所 / 巨潮资讯；
- 公司投资者关系记录 / 官网；
- 权威行业资料。

每条尽量包含：**来源名称、发布日期、对应内容、可访问 URL**。

不要为了数量罗列大量低价值链接。
