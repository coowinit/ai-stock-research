# 重点股票 AI 研究模板

> **用途：第一次系统研究一只新股票时使用。**  
> 目标不是直接判断“买不买”，而是判断这家公司是否值得进入长期重点研究池，并生成一份可以继续整理为 `stocks/股票代码-股票名称.md` 的基础研究结果。

---

# 一、使用方法

适用场景：

```text
第一次发现一只股票
↓
还没有长期研究档案
↓
复制本模板中的 AI 提问内容
↓
交给支持联网研究的 AI
↓
核验重要事实和来源
↓
判断：
值得重点研究 / 继续观察 / 暂不研究
↓
如果值得
↓
建立正式 stocks/股票档案
```

不适合用于：

- 每日短线涨跌复盘
- 已有股票档案的季度增量更新
- 单纯技术买卖点分析
- 自动荐股

已有长期档案后，应优先使用该股票文件末尾的：

> **AI重新研究与更新模板**

进行增量更新。

---

# 二、研究原则

整个研究必须严格区分：

```text
【事实数据】
已经发生并且可以核验的信息

【市场预期】
市场、机构、产业链对未来的主要预期

【投资判断】
基于事实与预期形成的分析

【未核验】
暂时找不到可靠公开来源的信息
```

---

# 三、禁止出现的常见错误

AI研究时不要：

- 因为公司属于热门行业就自动给出积极结论；
- 因为股价近期上涨就反推公司基本面优秀；
- 把“规划产能”写成“实际产能”；
- 把“送样”写成“批量出货”；
- 把“客户验证”写成“已经形成收入”；
- 把“市场预测”写成“公司已经实现”；
- 只看归母净利润，不看扣非利润和现金流；
- 只看营收增长，不看利润率和资本回报；
- 把媒体传闻直接当公司公告；
- 用大量MACD、KDJ等技术指标替代公司研究；
- 直接给出“强烈买入”“一定上涨”等结论。

# 四、AI 通用提问模板

复制下面内容，并替换股票名称、股票代码和研究日期。

```text
请对【股票名称：______】【股票代码：______】进行一次“重点股票首次研究”。

研究截止日期：【______】

本次研究的目标不是简单判断股价涨跌，也不是直接给出“买入/卖出”建议。

真正需要回答的是：

“这家公司为什么值得研究？核心投资逻辑是什么？目前有多少已经兑现？最大风险在哪里？是否值得进入长期重点研究池？”

请优先使用最新、可核验的公开资料。

资料优先级：

1. 公司年报、半年报、季报
2. 公司正式公告
3. 上海证券交易所 / 深圳证券交易所 / 北交所 / 巨潮资讯
4. 公司投资者关系活动记录
5. 公司官网
6. 权威行业资料
7. 高可信财经媒体

如果不同来源数据冲突，以公司正式披露和交易所公告优先。

所有分析必须严格区分：

【事实数据】
已经发生并可以核验的信息。

【市场预期】
市场、机构、产业链和客户对未来的主要预期。

【投资判断】
基于事实和预期形成的判断。

【未核验】
目前没有可靠公开资料支持的信息。

--------------------------------

一、30秒看懂公司

请先用最简单的语言回答：

1. 公司到底是做什么的？
2. 靠什么赚钱？
3. 当前最重要的业务是什么？
4. 当前最大的增长来源是什么？
5. 当前最大的经营问题是什么？
6. 当前最大的风险是什么？

最后用一句话给出：

【一句话公司定位】

要求：
不使用空泛的“行业龙头、前景广阔、技术领先”等宣传式表达。

--------------------------------

二、基础信息

请整理：

- 公司名称
- 股票代码
- 上市市场
- 所属行业
- 控股股东
- 实际控制人
- 主要业务
- 核心产品
- 主要客户
- 主要市场
- 海外收入占比（如适用）

只保留真正影响投资研究的信息。

--------------------------------

三、公司到底靠什么赚钱

请用普通投资者容易理解的语言解释：

1. 谁给公司付钱？
2. 客户为什么选择它？
3. 收入如何产生？
4. 利润主要来自哪些产品或业务？
5. 哪些业务收入大但利润低？
6. 哪些业务规模不大但盈利质量高？

如果公司业务较多，请给出：

【收入结构表】

至少包含：
- 业务
- 收入
- 收入占比
- 同比增长
- 毛利率

如无法获得完整数据，请明确标记“未披露”。

--------------------------------

四、为什么值得关注

请不要写超过5条。

重点回答：

1. 行业是否处于长期增长方向？
2. 公司是否处于产业链关键位置？
3. 公司是否存在明显竞争优势？
4. 是否存在新的成长曲线？
5. 是否存在盈利能力改善或价值重估可能？

每一条都要说明：

“为什么这件事可能影响未来收入、利润或估值？”

--------------------------------

五、核心投资逻辑

请从全部信息中只保留最重要的3—5条。

每条按照：

【逻辑】
↓
【事实依据】
↓
【未来需要验证什么】

格式输出。

例如：

核心逻辑1：
行业需求增长

事实依据：
最新订单、销量、客户资本开支等。

未来验证：
未来几个季度订单和收入是否继续增长。

不要只写：
“行业空间巨大”。

--------------------------------

六、核心竞争优势

请检查公司的真正优势来自哪里：

- 技术
- 成本
- 客户
- 品牌
- 渠道
- 规模
- 供应链
- 资源
- 牌照
- 制造
- 全球交付

每个优势必须用结果验证，例如：

- 市场份额
- 毛利率
- 客户稳定性
- 良率
- 成本
- ROE
- 现金流

如果找不到经营结果验证，请标记：

“优势仍需验证”。

--------------------------------

七、成长驱动

请判断未来3—5年增长主要来自：

1. 行业整体增长
2. 市场份额提高
3. 新产品
4. 新客户
5. 新市场
6. 产品价格或价值量提升
7. 产能扩张
8. 海外业务
9. 并购
10. 其他

请按重要性排序。

并区分：

【已经兑现】
【正在兑现】
【仍属于预期】

--------------------------------

八、新业务成熟度

如果公司存在新产品、新技术或第二增长曲线，请逐项判断：

- 研发
- 样品
- 客户验证
- 小批量
- 批量
- 快速放量
- 规模盈利

禁止：

把“研发”写成“商业化”。

把“送样”写成“已经放量”。

把“产能规划”写成“实际产量”。

--------------------------------

九、最新经营状态

请列出最近3—5个主要报告期的核心数据：

- 营业收入
- 营收同比
- 归母净利润
- 归母净利润同比
- 扣非净利润
- 毛利率
- 净利率
- ROE
- 经营现金流

重点回答：

1. 收入是在加速、稳定还是放缓？
2. 利润是否快于收入增长？
3. 扣非利润是否健康？
4. 毛利率是在改善还是恶化？
5. ROE是在改善还是下降？
6. 现金流是否匹配利润？

最后判断：

【当前经营状态】
明显改善 / 改善 / 稳定 / 转弱 / 明显恶化

--------------------------------

十、财务质量

重点检查：

- 应收账款
- 存货
- 经营现金流
- 自由现金流
- 有息负债
- 资本开支
- 固定资产
- 在建工程
- 商誉
- 资产减值

重点寻找：

1. 收入增长但现金流变差
2. 存货增长明显快于收入
3. 应收明显快于收入增长
4. 大规模扩产但利用率不足
5. 大额并购商誉
6. 长期依赖政府补助
7. 非经常性损益对利润影响过大

最后判断：

【财务质量】
优秀 / 良好 / 一般 / 较差

并解释原因。

--------------------------------

十一、行业与竞争格局

请回答：

1. 行业处于什么生命周期？
2. 当前景气处于：
   低谷 / 复苏 / 成长 / 繁荣 / 下行
3. 主要竞争对手是谁？
4. 公司市场份额如何？
5. 行业是否容易价格战？
6. 客户议价能力如何？
7. 新进入者是否容易进入？

重点判断：

“行业增长最终是否能够转化成公司利润？”

--------------------------------

十二、市场预期

请严格把市场预期和公司事实分开。

列出市场当前最主要的3—5个乐观预期。

然后逐条判断：

- 已兑现
- 部分兑现
- 尚未兑现
- 过度乐观
- 无法核验

重点回答：

“当前市场已经提前交易了什么？”

--------------------------------

十三、真正的预期差

不要简单回答：

“公司未来增长空间大”。

请寻找：

1. 市场可能低估了什么？
2. 市场可能高估了什么？
3. 哪个变量如果超预期，最可能改变盈利？
4. 哪个变量如果低于预期，最可能导致估值下降？

最多保留3条。

--------------------------------

十四、股东与资本行为

请检查：

- 控股股东
- 实际控制人
- 前十大股东
- 重要机构持仓
- 大股东增减持
- 回购
- 分红
- 股权激励
- 股权质押
- 司法冻结
- 控制权风险
- 并购
- 大规模融资

不要把普通机构持仓变化自动解释成：

“大资金看好”。

只保留真正可能改变长期公司价值的信息。

--------------------------------

十五、主要风险

不要写“市场风险、宏观风险”等空泛内容。

只保留最可能改变公司投资逻辑的3—6个风险。

例如：

- 行业需求下降
- 客户流失
- 市场份额下降
- 毛利率下降
- 新产品延期
- 产能利用率不足
- 大客户依赖
- 海外政策
- 技术路线变化
- 现金流恶化
- 股东治理风险

每个风险说明：

“如果发生，会具体影响收入、利润还是估值？”

--------------------------------

十六、逻辑证伪条件

这一部分必须非常明确。

请回答：

“未来出现什么可核验事实后，原投资逻辑应该被重新评估？”

最多5条。

要求证伪条件必须是：

- 可以观察
- 可以核验
- 能够真正改变投资判断

不要写：

“股价下跌”。

除非研究目标本身是短期趋势交易。

--------------------------------

十七、当前最重要的三个观察点

从全部信息中只选择：

> 未来最可能改变投资判断的3个变量。

不要超过3个。

每个变量说明：

1. 当前状态
2. 下一次验证时间
3. 什么结果代表强化
4. 什么结果代表弱化

--------------------------------

十八、是否值得进入重点研究池

请综合判断：

- 行业空间
- 公司竞争力
- 成长确定性
- 财务质量
- 市场预期
- 风险收益特征
- 可跟踪性

最后只选择：

【A：值得进入重点研究池】
公司逻辑清晰，存在长期研究价值，值得建立独立 stocks 档案。

【B：值得继续观察】
产业或公司有价值，但关键变量尚未充分验证，暂时不需要建立完整长期档案。

【C：研究价值一般】
存在一定机会，但竞争力、成长质量或风险收益关系一般。

【D：目前不值得继续投入大量研究时间】
逻辑不清晰、财务质量较差、风险过高或缺乏明确研究价值。

必须解释选择原因。
```

# 五、AI 返回后怎么处理

AI完成研究以后，不建议直接把全文原样放进 `stocks/`。

推荐继续做一次人工整理：

```text
AI完整研究
↓
核验重要数据
↓
删除重复内容
↓
只保留真正影响判断的信息
↓
确认A / B / C / D
```

# 六、A / B / C / D 对应动作

| 评级 | 后续动作 |
|---|---|
| **A** | 建立 `stocks/股票代码-股票名称.md` |
| **B** | 暂时保存研究结果，等待关键变量确认 |
| **C** | 不进入核心研究池，必要时偶尔观察 |
| **D** | 暂停研究，把时间投入更有价值的公司 |

---

# 七、评级不是股票评分

A / B / C / D 判断的是：

> **是否值得投入长期研究时间。**

不是：

```text
A = 一定上涨
D = 一定下跌
```

例如：

> 一家非常优秀的公司，如果市场预期已经极高，依然可能值得进入A类研究池。

因为：

> **研究价值 ≠ 当前买入价值。**

# 九、什么时候不要立即建档

即使行业很热门，出现以下情况时也建议先放在B类观察：

- 公司刚刚进入新业务，尚未产生收入；
- 只有送样，没有量产；
- 新产能规模很大，但利用率未知；
- 利润主要依赖非经常性收益；
- 客户和订单缺乏可靠来源；
- 市场已经给出非常高的未来预期；
- 股东或治理存在重大不确定性；
- 关键事实仍无法核验。

原则：

> **宁可少研究几只，也不要把 stocks 目录变成普通自选股列表。**
