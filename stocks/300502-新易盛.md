# 三、为什么值得长期关注

新易盛值得研究，并不是因为：

> “光模块是AI热门题材。”

真正值得研究的是：

> **公司已经把AI数据中心高速互联需求，转化成了非常强的收入、利润、毛利率和现金流。**

很多科技公司处于：

```text
技术
→
送样
→
验证
→
等待收入
```

而新易盛当前已经处于：

```text
客户需求
→
大规模订单
→
扩产
→
高速产品放量
→
收入增长
→
利润增长
```

因此它更像：

> **已经进入强盈利兑现阶段的AI基础设施核心供应商。**

# 五、光模块为什么在AI时代越来越重要

AI数据中心的核心问题不仅是：

> GPU算力够不够。

还包括：

> **GPU之间能不能高速交换数据。**

大型AI集群需要大量服务器、交换机和GPU进行通信。

随着算力规模提升，网络速率不断升级：

```text
100G
→
200G
→
400G
→
800G
→
1.6T
→
更高速率
```

因此高速光模块同时获得两种增长：

```text
AI集群规模扩大
+
单个连接速率提升
```

这就是新易盛当前增长最重要的产业基础。

# 十二、为什么硅光值得长期跟踪

速率越高，传统光模块越面临：

- 功耗
- 散热
- 器件数量
- 集成复杂度
- 成本

压力。

硅光的潜在优势在于：

- 高集成度
- 规模化制造
- 功耗优化
- 成本下降空间

所以未来不应该简单问：

> “硅光有没有？”

而要看：

```text
硅光占比
+
良率
+
成本
+
毛利率
+
客户应用
```

是否同步改善。

# 二十三、Q2为什么明显加速

公司2026年7月投资者交流给出了几个原因：

1. 订单交付需求继续增长。
2. 行业景气仍处高位。
3. Q1供应链紧张问题从Q2开始逐步缓解。
4. 前期核心原材料备货和锁定逐渐产生效果。
5. Q1较大的汇兑损失影响在Q2明显收窄。
6. 产品结构继续优化。

所以目前更合理的判断是：

> **Q2增长并不是单纯依靠会计因素，订单、供应链和产品结构都在改善。**

---

# 二十四、订单能见度：目前仍然非常强

> **0.17亿元**

> **6.82亿元**

增幅非常大。

> 主要是为了提前锁定原材料供应。

> 核心原材料整体仍处于比较紧张的状态。

> **仍偏紧，但正在改善。**

> 已经完全恢复正常。

# 二十八、为什么当前库存大幅增加

公司业务属于订单驱动模式。

当前增长阶段需要：

- 提前锁定光芯片
- 锁定电芯片
- 备货
- 保障订单交付
- 支撑新产品放量

- 产品降价
- 技术迭代导致库存减值
- 备货过度

> **约5.33亿元**

所以库存绝不能忽略。

> **25.4%**

> **应收增长速度是否长期快于收入增长速度。**

> **高利润能否继续变成真实现金。**

> “业绩会不会增长？”

而是：

> **这种增长速度和接近50%的毛利率能维持多久。**

换句话说：

> **公司基本面很强，不等于投资风险很低。**

基本面越强、市场预期越高：

> 对未来兑现的要求也越高。

所以以后研究新易盛必须同时观察：

```text
高速增长
+
高毛利率
+
现金流
+
海外风险
```

四件事。

只要其中一项发生重大改变：

> 都可能显著改变市场对公司的估值方式。
