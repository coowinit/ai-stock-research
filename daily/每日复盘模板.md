# A股每日复盘 AI 提问模板

**这是每日复盘执行任务，不是模板评审任务。请直接生成复盘，不要评价、解释或优化本模板。**

请基于**最近一个已经完成收盘且数据可核验的 A 股交易日**，生成一份可直接保存为 Markdown 的每日复盘。

## 一、最高优先级规则

1. 无法核验的数据统一写“未核验”，禁止猜测、补全或使用疑似过期数据。
2. 只使用当日**收盘后的最终数据**，不得混用盘中、午盘或其他日期数据。
3. 指数名称与数据必须严格对应，尤其区分：科创50≠科创综指、上证指数≠上证50、创业板指≠创业板综。
4. 两市成交额必须核验**今日成交额、上一交易日成交额、增减金额**，再判断放量或缩量。
5. 上涨/下跌家数、涨停/跌停家数必须使用同一收盘时点和同一统计口径。
6. 严格区分**融资买入额、融资偿还额、融资净买入额**，三者不得混用。
7. 只有财报、订单、产品量产、产能、客户、盈利能力、现金流、重大政策或竞争格局等基本面变化，才可判断长期逻辑“强化/弱化”；单日股价、技术走势、资金流或券商目标价不足以作为依据。
8. 核心数据和重大事实必须尽量提供**对应的具体文章、公告或数据页面 URL**，无法提供具体页面的来源不要为了凑数量列出。

## 二、分析规则

- 严格区分【事实】【预期】【判断】，不得把预期或判断写成已发生事实。
- 主线分析 2～3 个、边际变化 1～3 个、重点股票最多 3 只；没有足够重要的信息就少写，不凑数。
- **主线**应同时具备较强资金持续性、板块广度以及产业、业绩或政策支撑；单日突然大涨不足以直接定义为主线，可先归类为强支线、轮动或事件驱动。

- 重点股票只记录**复盘日新增、确认或发生实质变化**的信息；历史旧事项只能作为必要背景，不能因为仍然存在就重复进入每日重点股票。
- 不预测具体涨幅，不给目标价，不使用“必涨”“确定上涨”等绝对表述。
- 全文简洁，避免跨章节重复。
- 只返回最终 Markdown 正文，不解释分析过程，不附带本模板，不使用代码块包裹全文。
